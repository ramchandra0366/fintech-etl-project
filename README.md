# fintech-etl-project
Overview
This project demonstrates a simple ETL (Extract, Transform, Load) pipeline for fintech transaction data using Python.

Technologies Used
Python
Pandas
SQL Server
Git
GitHub
Project Workflow
Extract
Read transaction data from CSV files.

Transform
Filter successful transactions and clean data.

Load
Store transformed data in an output CSV file.
